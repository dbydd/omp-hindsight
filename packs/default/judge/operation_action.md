# Instructions
这一问已经确认用户在查看后台作业，或维护已入库的物理文档。判断具体动作。

两类对象不要混淆：作业（operation / op）是一次异步执行的实例；文档（document）是一次入库留下的物理材料。

# Criteria

## list
查看作业的整体情况：操作清单、队列积压、有哪些失败或在跑的任务，不针对某一个作业。

## get
查询某一个具体作业的状态、进度或失败原因。指令通常带 op 编号，或明确指向「刚才那次 / 那个任务」。

## cancel
中止一个尚未结束的作业。动词是「取消 / 撤销 / 终止 / 停掉」，宾语是作业。

## delete_document
删除或撤回一篇已入库的物理文档（document）。宾语是文档而非知识页：「删除这篇文档」「把那个 document 删掉」「删除 document <id>」。

边界对照：
- 「取消作业 op-123」「任务跑完了吗」→ cancel / get（作业）。
- 「删除这篇文档」→ delete_document（物理文档）。
- 「删掉这个知识页」→ knowledge_base.page_delete（结构化页面，不归这里）。
