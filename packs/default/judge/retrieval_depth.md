# Instructions
这一问已经确认用户在向记忆库提问。判断用户期望的作答深度（recall 还是 reflect）：

- **recall（事实检索）**：用户在**调取、检索或提取记忆库中已有的记录、事实切片或既有结论**。
  - 明确指令：**使用「召回……」「从 X 库召回关于 Y 的记忆」「查一下……」「找一下……」语句检索某个实体、主题、论文或关键词的记忆切片**，是标准的 recall 操作，坚决判定为 **recall** 并给出高置信度。
  - 目标是具体参数、配置值、代码名、某次提交，或者调取沉淀好的某项离散结论、某篇论文的记忆切片、单条测试事实。
- **reflect（深度综合与多篇归纳）**：用户在要求系统**跨多篇记忆进行现场因果解释、方案对比、利弊评估、全貌综述或宏观归纳**。
  - 复合问句判定：**凡是句中明确出现「综合出……」「综合回答……发现了什么」「总结……思路」「对比……差异」「解释为什么……」等分析归纳动词，即使前面有「翻一遍所有记忆」「翻查记忆」等检索铺垫，其最终目标是归纳综合，坚定选择 reflect 并给出高置信度！**

# Criteria

## recall
从记忆库中调取已有的离散事实、参数或某主题/论文的既有记忆切片：
- 显式召回实体或论文记忆（「从 vault bank 召回关于 pnp-corrector 的记忆」「从 agent-testrole 召回 testrole 的探索记录」）。
- 询问具体的参数值、配置常量、提交哈希或命令名称（「重试上限是多少」「当时选的哪个模型」「哪次提交改了 vchord」）。
- 检索既有的某项结论或历史记录（「查一下归档库里关于 embedding 的结论」「之前关于 ssot 校验的结论是什么」）。
- 批量过滤包含某关键词的事实（「找出所有提到 observationScopes 的事实」）。

## reflect
要求系统进行现场多角度综合、因果推理、方案对比或宏观论证：
- 宏观总结与跨文档综合提炼：
  - 「综合回答：testrole 对 omp-hindsight 插件的探索到目前为止发现了什么」
  - 「翻一遍我存进 vault bank 的所有记忆，综合出 SDANet 和 pnp-corrector 两篇论文各自的要点」
  - 「总结 judge 分层的整体思路」「综述 Hindsight 与 omp history 的分工」
- 因果机制与决策动机解释（「解释一下为什么 observationScopes 必须显式配置」「为什么最后选了 nemotron 而不是 bge」「为什么 retry 队列要自己实现」）。
- 方案与技术对比（「回顾并比较 deploy 与 release 两条流水线的差异」「对比 recall 与 reflect 的成本差异」）。
- 风险代价评估（「评估迁移到官方 1.1 的风险与代价」）。

边界对照：
- 「从 vault bank 召回关于 pnp-corrector 的记忆」→ recall（调取实体切片，标准 recall，高置信度）。
- 「找出所有提到 observationScopes 的事实」「查一下归档库里关于 embedding 的结论」→ recall（调取既有事实，高置信度）。
- 「综合回答：testrole 对 omp-hindsight 插件的探索到目前为止发现了什么」→ reflect（宏观综合发现，高置信度）。
- 「翻一遍我存进 vault bank 的所有记忆，综合出 SDANet 和 pnp-corrector 两篇论文各自的要点」→ reflect（跨论文多文档归纳，高置信度）。
- 「解释一下为什么 observationScopes 必须显式配置」→ reflect（解释决策因果机制，高置信度）。
