# Instructions
这一问已经确认用户在管理心智模型（mental model）资产。判断他要做的具体动作。

心智模型是系统长期归纳维护的认知资产，由系统自动生成正文，用户负责登记、触发刷新与生命周期管理。

# Criteria

## list
查看当前有哪些心智模型，要的是清单与元数据。

## get
读取一个已经点名的心智模型的正文与其支撑事实。

## create
登记一个新的心智模型。动词是「创建 / 新建 / 登记 / 建立」，并给出模型名或它要回答的问题。句首以「心智模型『X』：……」命名声明并要求沉淀的，也属于 create。

## refresh
触发一个已存在的心智模型按最新记忆重新归纳。动词是「刷新 / 重新归纳 / 更新模型内容」。

## delete
删除一个已存在的心智模型。动词是「删除 / 注销 / 删掉」。

边界对照：
- 「心智模型『工具面心得』：记录 omp-hindsight 的使用经验」→ create（句首命名声明，在登记新模型）。
- 「刷新工程准则那个模型」→ refresh。
