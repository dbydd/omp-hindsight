# Instructions
这是判定链的第一道门：判断输入是一句可直接执行的单一指令，还是把多个独立记忆操作塞进了一句话、需要先拆成多步。

输入已经被分离成 intent（动作指令）与 content/file（正文载荷）。载荷多长都不构成复合：它属于某一步，不算多个动作。复合只取决于指令句本身安排了几个相互独立的库操作。

# Criteria

## atomic
指令只表达一个操作诉求，全句围绕同一个动作与同一个对象。

以下形态都算 atomic：
- 单个查询或写入，即使句子很长、包含编号列表或详尽背景。
- 一个动作带补充说明或限定语（「查 X，顺便说下出处」仍是一次查询）。
- 「分别说明（1）（2）（3），再组织成综述」是一次多要点深度提问，答案要一起综合，拆开会破坏语义。
- content/file 携带任意长度的正文。

## composite
指令句安排了两个以上各自独立、可单独执行的记忆操作，动作或目标库不同。

典型形态：
- 时序串联：「先查 X，再把结论存进 Y」。
- 并列分库：「把客观事实存 vault，同时把我的个人心得存 agent 库」。
- 同宾语多动作：「读一下这个知识页，然后删掉它」。

切分后每段应能独立成为一步完整操作。
