# 两阶段参数物化：原文切片与确定性装配机制

当分层判定网络锁定了具体的叶动作（例如 `kb.page.create` 或 `recall`）之后，系统必须收集执行该 API 所需的具体字段值（如标题、正文、查询词、标签与数值参数）。

本系统放弃了让大模型直接输出包含业务参数的 JSON 对象的传统做法，采用严格的两阶段参数物化机制（Two-stage Parameter Materialization）。

---

## 传统单阶段模型直接填充 JSON 的缺陷

在常见实践中，开发者通常为大模型提供一个完整的 JSON Schema，要求模型理解用户意图并直接生成填充完整的 JSON 请求体。这种做法在处理代码、专业文献和结构化技术数据时存在三个根本性缺陷：

1. **不可避免的文本自动润色与语义失真**：
   大语言模型的底层生成机制天然偏向于语言顺畅性。在复述长段文本时，模型会自主修饰标点符号、调整词序、删除代码注释甚至格式化空格。当用户要求记录一段包含特殊符号的 SQL 语句或精确的数学公式时，模型直接生成的正文极易出现字符级偏差。
2. **长文本转义导致 JSON 解析崩溃**：
   当用户需要保存的内容包含多行回车、内部双引号、反斜杠或嵌套 JSON 时，模型在生成时极易产生转义遗漏或非法字符，直接引发 `JSON.parse` 运行时异常，导致整个调用链路中断。
3. **隐式参数幻觉**：
   面对非必填或未明确提及的配置字段，模型会尝试根据“常识”猜测默认值填入 JSON 中，使得未经用户授权的配置悄然生效。

---

## 两阶段参数物化流程

两阶段物化将“定位信息所在位置”与“提取物理内容”彻底切开：

```
[ 用户原始输入 intent / meta ]
              │
              ▼
   【第一阶段：X1 结构化提取节点】
   - 模型只输出字符起止偏移量: span = [start, end]
   - 模型只输出数值与受限枚举: budget = "mid"
   - 严禁模型输出正文文字
              │
              ▼
   【第二阶段：D2 确定性物化节点 (TypeScript 代码)】
   - 严格类型校验 (Zod / TypeCheck)
   - 内存原始字符串物理切片: content = rawInput.slice(start, end)
   - 外部文件通过宿主只读接口读取原始字节
   - 组装最终不可变的 API 请求 Payload
```

### 第一阶段：X1 结构化提取节点（模型只输出指针）

在目标动作确定后，系统调用会话模型并传入针对该动作的专属轻量 Schema。模型在此阶段承担“信息定位器”的单一职责：

- **文本切片指针（Span）**：对于标题、正文、检索词等自由文本字段，模型输出一个长度为 2 的整数数组 `[start, end]`，代表该字段内容在原始输入字符串中的起始与结束字符索引。
- **元数据指针（Meta Pointer）**：若内容来源于 `meta` 字典，模型输出 JSON Pointer 路径（例如 `"/sources/text"`）。
- **受限枚举与数值**：直接输出明确受限的枚举值（例如 `budget: "low"`）或正整数。

### 第二阶段：D2 确定性装配节点（底层代码物理切片）

D2 节点完全由 TypeScript 代码编写，不调用任何大模型：

1. **边界安全校验**：校验模型返回的 `start` 与 `end` 索引是否合法，确保未越界且 `start < end`。
2. **纯净内存切片**：调用原生的 `string.slice(start, end)` 直接从宿主保存的原始输入副本中复制子字符串。
3. **外部文件读取**：当来源指向外部文件时，直接调用宿主只读文件系统接口，将文件的原始二进制字节或 UTF-8 内容读入内存，同时计算 SHA-256 哈希值完成完整性锁定。
4. **组装不可变 Payload**：将切片提取的纯净文本与确定性默认值组装为强类型对象，完成向底层 HTTP Client 的派发。

---

## 两阶段物化的工程收益对比

| 评估维度 | 传统直接生成 JSON 方案 | 两阶段参数物化方案 |
|---|---|---|
| **文本字符一致性** | 存在模型自主润色、标点替换风险 | **100% 逐字符严格一致** |
| **代码与公式保真度** | 换行和特殊缩进可能被抹平 | **原始字节无损保留** |
| **JSON 转义失败率** | 在长文本和包含引号内容下高发 | **0%（字符串不经过模型二次序列化）** |
| **参数幻觉** | 模型自主脑补缺失字段 | **杜绝脑补，未提及字段严格置空** |
| **审计与确定性回放** | 难以判断模型是理解错误还是生成失误 | **原句指针与切片结果完全可审计** |
